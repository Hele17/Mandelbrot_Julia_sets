# Mandelbrot_Julia_sets
Numerical representation and visualization of the Mandelbrot and Julia sets using Python.

## Description

This project explores the numerical representation and visualization of the Mandelbrot and Julia sets using two-dimensional arrays and iterative methods.

The project includes:

- Generation and visualization of Mandelbrot and Julia sets.
- Analysis of the convergence and divergence of the iterative process.
- Visualization of the number of iterations required for convergence or divergence.
- Representation of the resulting fractal structures.

## Technologies and Libraries

- Python
- NumPy
- Matplotlib
